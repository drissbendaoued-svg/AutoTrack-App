# AutoTrack

**متابعة سيارتك بذكاء**

AutoTrack هو تطبيق Android لإدارة السيارة ومتابعة أهم بياناتها في مكان واحد.

## المزايا

- تذكيرات وثائق السيارة: التأمين، الفحص التقني، الضريبة السنوية، رخصة السياقة والبطاقة الرمادية.
- متابعة الصيانة وتغيير الزيت والفلاتر.
- تسجيل الوقود وحساب اللترات والتكلفة والاستهلاك.
- تسجيل مصاريف السيارة حسب الفئة.
- تقارير مالية شهرية وسنوية مع تصدير Excel وPDF.
- نسخ احتياطي واستعادة البيانات.
- تنبيهات متعددة قبل مواعيد الاستحقاق.
- دعم أكثر من سيارة.
